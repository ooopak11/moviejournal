# 구현 일정 (체크포인트 기반)

## 목표

출판 전 비공개 상태에서 다음을 만족하는 협업 번역 사이트 구축:

- Google/GitHub 로그인 기반 빠른 편집 참여
- 키워드/날짜 중심 검색
- 책에 가까운 읽기 레이아웃
- 롤백 가능한 운영 안전장치

## 7일 일정

1. Day 1: 기획 확정
- 권한 정책 확정
- 메타데이터 모델(날짜/태그/원문/번역 상태) 확정
- 페이지 템플릿/명명 규칙 확정
- Checkpoint A: 정책/모델 승인

2. Day 2: 로컬 인프라
- Docker Compose로 BookStack + MariaDB 기동
- 볼륨/백업 기본 동작 확인
- Checkpoint B: 로컬 접근/운영 방식 승인

3. Day 3: 인증/권한
- Google/GitHub OAuth 연결
- 자동 가입 활성화
- 역할 모델 및 편집 권한 검토
- Checkpoint C: 로그인→편집 흐름 승인

4. Day 4: 콘텐츠 구조
- Book/Chapter/Page 골격 생성
- 연/월/일 인덱스 페이지 구성
- 샘플 엔트리 입력
- Checkpoint D: 정보구조 승인

5. Day 5: 읽기 레이아웃
- 원문/번역 2열 패턴 적용
- BookStack 커스텀 CSS 적용
- Checkpoint E: 시각 방향 승인

6. Day 6: 탐색/검색 강화
- 날짜 내비게이션 확정
- 태그/키워드 규칙 확정
- 편집자용 검색 가이드 작성
- Checkpoint F: 탐색성 승인

7. Day 7: 안정화/인수
- 롤백/리비전 운영 절차 확정
- 백업/복구 점검
- 퍼블리시 전 체크리스트 확정
- Checkpoint G: 베타 완료 승인

## 이번 스프린트 제외

- 공개 런칭
- 비로그인 익명 편집
- OCR 자동 파이프라인
